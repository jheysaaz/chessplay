# chessplay

Initial project for a chess website built with **Next.js**, **TypeScript**, and **TailwindCSS**.

## Features (initial)

- 1v1 local play entry point
- Room play entry point (create/join flow placeholder)
- Machine play entry point (bot match placeholder)
- Chess board preview UI

## Getting started

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Scripts

- `npm run dev` — run local development server
- `npm run build` — production build
- `npm run start` — run production server
- `npm run lint` — lint with ESLint
